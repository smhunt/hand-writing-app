HANDWRITING TEMPLATE INSTRUCTIONS
==================================

To create your handwriting template PDF:

1. Create a grid of boxes (each ~1 inch square)
2. Label each box with a character (A-Z, a-z, 0-9, punctuation)
3. Arrange in rows (e.g., 6-8 columns per row)
4. Include alignment markers in corners for easier detection
5. Save as PDF format

Recommended layout:
- Page size: Letter (8.5" x 11") or A4
- Box size: 1" x 1" (72pt x 72pt)
- Font size for labels: 8-10pt, placed outside or top-left of boxes
- Include at least: A-Z (uppercase), a-z (lowercase), 0-9, common punctuation

Character order suggestion:
Row 1: A B C D E F G H
Row 2: I J K L M N O P
Row 3: Q R S T U V W X
Row 4: Y Z a b c d e f
Row 5: g h i j k l m n
Row 6: o p q r s t u v
Row 7: w x y z 0 1 2 3
Row 8: 4 5 6 7 8 9 . ,
Row 9: ! ? - ' " ( ) :

You can create this template using:
- Microsoft Word or Google Docs (insert table)
- Adobe Illustrator or similar design software
- Python with reportlab library
- LaTeX
- Online template generators

Once created, place the PDF file at:
  backend/public/template.pdf

Users will then be able to download this template from the app.
